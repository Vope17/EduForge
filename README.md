# EduForge

教學內容平台：依**課程 → 章 → 課次**整理教材，每個課次依序是**來源 → 知識 → 產出**。來源是你的教材（PDF、PPTX、DOCX）；AI 逐頁讀完（文字加頁面影像）整理成帶出處的知識；教案、學習單、講義與課堂簡報都從這份知識生成。沒有來源，就沒有知識，也沒有產出。

架構沿用 [Paper2Lab](../Paper2Lab)（Go 後端、Vue 3 前端、SQLite、單一服務），規劃見 [docs/rebuild-plan.md](docs/rebuild-plan.md)。

## 目前進度

- 第 1 期完成：課程／章／課次結構與排序、設定繼承、`docread`（PDF／PPTX／DOCX 逐頁讀取）、知識的逐頁閱讀與覆蓋率。
- 第 2 期完成：**講義**（本節重點、概念講解、例題與詳解、常見迷思、重點整理、課後練習）與**課堂簡報**（含講稿）的生成、編輯、匯出，前面課次的概念當背景，講義與簡報可拖曳框選後請 AI 修改。
- 第 3 期完成：**教案**（寫進表格式 Word 表單，可換成學校的表單）、**學習單**（學生版與教師版）、**教學大綱與進度表**（課程層級，輸出 Word 與可貼進教務系統的純文字）。
- 還沒做：真實教材驗收與切換（第 4 期）；教案、學習單、教學大綱的 AI 修改。

## 啟動

```sh
docker compose up --build -d --wait
```

預設開啟 <http://127.0.0.1:8081>。更換連接埠：`EDUFORGE_PORT=18081 docker compose -p eduforge-next up --build -d --wait`（新資料卷，不影響舊資料）。首次啟動建立本機使用者。ChatGPT 訂閱僅供登入者本人使用。

在「設定 → 模型連線」登入 Codex（ChatGPT 訂閱）、Claude Code，或填 API Key。不連模型時，上傳與解析仍可使用，知識只有依關鍵字擷取的原文段落。

## 課程結構

- **課程**：預設設定（教學對象、程度、每節時長 50 分鐘、講義深度）。
- **章**：可排序，只儲存它覆蓋的設定。
- **課次**：可排序，可不歸屬任何章（未分章，排在最前）。
- **教學順序**：未分章課次先，再依章與課次的順序。排在前面的課次視為學生已學過；後面課次讀教材時，會把它們的概念當作背景。
- 設定逐層繼承：課程 → 章 → 課次，空欄位沿用上一層。

## 產出

每個產出都從課次的知識生成，附出處，可編輯、有版本紀錄與復原重做、可套用你匯入的 Word／PowerPoint 模板。

- **講義**：六個固定段落；課後練習只有題目，沒有答案。下載 Word、PDF、HTML。
- **課堂簡報**：依課堂時間規劃張數（約每 2 分鐘 1 張），第一張學習目標、最後一張重點整理，每張附講稿。下載 PPTX、PDF、講稿 PDF。
- **教案**：基本資料、教學研究、單元與具體目標（認知、情意、技能）、三階段的教學活動表（目標代號、活動、時間、資源、評量）。活動時間合計必須等於課堂時間——不等時會標示，不會自動調整。匯出填進 Word 表單；「設定 → 模板」可匯入學校的表單。
- **學習單**：題型與題數自選，每題對應一個學習目標並附出處。下載學生版（沒有答案）與教師版（有答案與解析）。
- **教學大綱**（在課程首頁）：依章與課次的順序排進每週進度，另有評分方式與教科書；下載 Word、PDF 或純文字。
- **AI 修改**（講義與簡報）：開啟「AI 修改」後，勾選、Shift＋點擊，或在頁面空白處拖曳框選要改的區塊，說明怎麼改，逐塊比對後再接受。

## 來源與知識

`internal/docread` 把檔案讀成頁（或投影片）：文字、頁面影像、模式。文字很少的頁面（掃描檔、整頁是圖的投影片）標為「影像辨識」，由模型看影像讀，不會被拒絕。PPTX 的講者備註一併讀入，隱藏投影片略過。

知識由模型分批讀完每一頁寫成，分七類：學習目標、先備知識、核心概念與定義、公式與規則、例題與解答、常見迷思、圖表。每個要點標出引用的頁；原頁找不到的數字會提醒；來自影像辨識的要點會標示。讀取範圍（讀了幾頁、哪些頁沒讀到）顯示在知識頁，沒讀到的頁可以續讀。

## 開發與驗收

主機不需安裝 Go 或 Node.js，用 Docker 跑工具鏈：

```sh
scripts/dev.sh make check     # go vet、go test -race、型別、前端建置與測試
scripts/dev.sh make types     # 修改 Go struct 後重新產生 frontend/src/api/domain.ts
```

`scripts/dev.sh` 建置 `Dockerfile` 的 `dev` 階段（Go、Node、Poppler、LibreOffice），把專案掛進去執行。
