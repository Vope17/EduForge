# M4 課堂簡報

使用者已確認採用自建 Block 編輯器與三種版面：標題與內容、雙欄、圖文。這次優先提供簡報製作所需的樣板閘門、編輯、選取修改與修訂；M2 長期風格記錄、文檔完整 M3 介面、M7 跨類型來源另行實作。

## 模型與儲存

沿用 `artifact.Content`，由 `artifact_type` 區分 document／slides。slides 的根 Block 為投影片，具有 `layout`、`notes`、`children`。子 Block 可為 heading、paragraph、list、image，每頁恰有一個 heading。所有層級皆有獨立且穩定的 ID，並索引至 revision_blocks。新區塊由後端配發 ID；未知或重複的 ID 會被拒絕。

每份簡報 1–12 頁，每頁 2–8 個區塊；標題 120 字、段落 800 字、備註 2,500 字。圖片可使用空 URL 的位置說明；實際圖片限無帳密的 HTTPS 網址，由瀏覽器載入，不由後端擷取。生成只會回傳圖片位置與說明。

003 migration 在交易內搬移既有資料與外鍵鏈，保留原樣板／修訂 JSON；004 加入持久化生成工作；005 加入待確認的 patch。既有 migration 不變。

## 樣板與生成

Spec 的既有配色、字型、語氣與密度不變。簡報 layout 為 `title_body`、`two_columns`、`image_text`，example 恰為一頁，最多三個子區塊與少量備註。完整生成綁定確認的版本、版面、語言與頁數；後端拒絕不符合限制的模型輸出。

`internal/job` 逐一處理 SQLite 中的生成工作。API 立即回傳 202；工作開始時才取得生成鎖並計入每日額度。排隊中的工作可立即取消，執行中的工作透過 context 取消。失敗／取消後保留已確認的樣板供重試。重啟時將中斷工作重新排隊；若產物已寫入，則補記為完成。無記憶體模型連線時，工作會明確失敗並提示重新連線。

進度為階段值：排隊 0、生成中 25、完成 100，並非模型 token 百分比。生成上限 180 秒，模型輸出最多 8,000 tokens；超時或無效結果可重試且仍計入使用額度。

## API

前綴 `/api/v1`，固定預設使用者；所有 id 端點先驗證產物類型，文檔與簡報無法互相操作。

| 方法與路徑 | 用途 |
|---|---|
| GET／POST `/slides` | 列表／建立，kind=`presentation`、slide_count=1–12、language=`zh-TW` 或 `en` |
| GET `/slides/{id}` | 需求、樣板、最新產物與最新工作 |
| POST `/slides/{id}/preview` | 以 template_version、feedback 產生一頁樣板 |
| POST `/slides/{id}/confirm` | 確認指定 template_version |
| POST `/slides/{id}/generate` | 以確認版本排隊，回傳 job_id |
| GET `/jobs/{id}` | 查詢 state、progress、error_code、cancel_requested |
| POST `/jobs/{id}/cancel` | 取消，JSON body `{}` |
| GET／POST `/slides/{id}/revisions` | 歷史／儲存、undo、redo、restore，與文檔 DTO 相同 |
| GET `/slides/{id}/revisions/{revision}` | 讀取不可變的歷史版本 |
| POST `/slides/{id}/patches` | base_revision、instruction、selection，回傳 proposal_id 與 changes 差異 |
| POST `/slides/{id}/patches/{proposal}/accept` | body `{}`，驗證版本後建立修訂；同版本重送不會重複寫入 |
| POST `/slides/{id}/patches/{proposal}/reject` | body `{}`，捨棄建議 |

## Selection → Patch

共用 `frontend/src/selection/` 支援跨頁多選、拖曳框選與文字反白。anchor 可指定 field=`text`／`notes`／`items.N`；未指定時表示該區塊全文（清單包含各項；投影片本身表示備註）。文字 offset 使用 UTF-16，end 不包含，與瀏覽器 textarea 一致。後端拒絕跨 surrogate 的範圍並合併重疊範圍。

模型只收到選取的文字片段、語言、標題與本次指示。只接受匹配選取片段 block_id／field／start／end 的 replacement；越界結果整份拒絕並記錄不含內容的事件。proposal 保存確認前的基準版本，接受時再次驗證範圍及現行版本，並在單一交易內寫入 revision。未選取文字、圖片網址、版面與 Block ID 都不會被 AI patch 改動。

## 驗證

執行 `make lint`、`make test`、`make build`。Go 測試涵蓋兩種語言與三種版面、確認閘門、頁數／ID／語言錯誤、不可變修訂、UTF-16 越界、只送選取內容、差異接受／拒絕／過期、工作取消／失敗重試／重啟回復，以及舊資料 migration。Vue 測試涵蓋語言預設／覆寫、確認後排隊與輪詢、重新載入後取消、備註／排序儲存、跨頁多選／diff 接受、播放鍵盤操作及共用矩形選取。模型測試全數使用 mock。

手動驗收：從 `/slides` 建立需求，確認樣板後生成，修改文字與備註並儲存；選取不同頁的兩處文字要求簡化，檢查 diff 並接受，再用復原／重做與歷史預覽檢查內容。播放時以方向鍵換頁、Esc 結束。字型由映像內 `/fonts/` 提供；實際中文排版仍需在瀏覽器驗收。前端首次下載兩套 TC 字型約 29 MB。
