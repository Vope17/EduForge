# M1 教學文檔

首頁的教學文檔入口可建立或重新開啟教案、學習單及講義。建立需求時，生成語言預設跟隨介面語言，可選擇繁體中文或英文。

在模型連線頁設定 API key 或授權 ChatGPT 訂閱後，教師可以產生樣板預覽、要求調整、確認當前版本，再生成完整文檔。樣板包含配色、字型、版面、語氣、內容密度及一至三個範例區塊。確認時記錄樣板版本，後端只接受以該版本開始完整生成。

編輯器支援標題、段落、清單、表格與 HTTPS 圖片連結。每次儲存、復原、重做或還原都建立新修訂，舊修訂可以獨立讀取。現有區塊在編輯及移動時保留 ID，新區塊由伺服器分配 ID。共用選取模組支援多區塊與文字範圍，文字 offset 使用 UTF-16 且終點不包含在範圍內。選取式 AI 修改留到 M3。

## 資料與生成服務

使用 `database/sql` 與 `modernc.org/sqlite`，每個連線開啟 foreign keys 和 WAL。正式資料位於 `document-data` volume，開發資料位於 `development-data`。啟動時自動套用編號 migration。`make migrate` 亦可單獨套用至正式資料 volume。

目前單一後端實例啟動時會復原中斷的生成狀態。生成失敗會保留上一次成功的樣板，或回到可重試的已確認狀態。`EDUFORGE_DAILY_GENERATIONS` 預設為每位使用者每日 30 次，以 UTC 日期計算，樣板、調整及完整生成的嘗試都計入。

LLM 業務介面位於 `backend/internal/llm`。模型連線頁提供 Chat Completions 相容 API key 輸入及 ChatGPT 訂閱 OAuth。後端以同一 provider 介面處理兩種連線。ChatGPT 授權後從官方模型目錄取得帳號可用模型，並使用串流 Responses API。API key 與 OAuth 權杖只暫存在後端記憶體，狀態 API 只回傳模型及連線資訊。測試使用 mock provider 與簽署的測試 ID token。

## API

下列路徑前綴為 `/api/v1/documents`。

| 方法 | 路徑 | 用途 |
|---|---|---|
| GET | 根路徑 | 列出文檔與生成需求 |
| POST | 根路徑 | 建立需求，傳入 `topic`、`audience`、`kind`、`language` |
| GET | `/{id}` | 讀取需求與目前文檔 |
| POST | `/{id}/preview` | 產生樣板，傳入 `template_version` 與選填的 `feedback` |
| POST | `/{id}/confirm` | 確認當前樣板，傳入 `template_version` |
| POST | `/{id}/generate` | 以 `template_version` 對應的已確認樣板生成完整文檔 |
| GET | `/{id}/revisions` | 列出歷史修訂 |
| GET | `/{id}/revisions/{revision}` | 讀取指定修訂 |
| POST | `/{id}/revisions` | 傳入 `base_revision`、`action` 與該動作的資料 |

儲存的 `action` 是 `save` 並附 `content`。復原與重做分別為 `undo`、`redo`。還原為 `restore` 並附 `target_revision`。樣板或文檔版本過期時回傳 HTTP 409。生成端點各有逾時，樣板最多 25 秒，完整文檔最多 55 秒。

## 驗收

執行 `make config`、`make lint`、`make test` 與 `make build`。套件鎖檔已由實際套件管理器產生並納入專案。

接好選定的 provider 後，以 `make up` 啟動。在首頁建立教學文檔，調整樣板並確認最新版，生成後修改及儲存。從歷史版本檢視舊內容，測試復原、重做和還原，再重啟容器確認資料仍在。


## 模型連線 API

`GET /api/v1/model-connection` 讀取狀態與 CSRF token。`PUT` 設定 API key 連線，`PATCH` 選擇已授權 ChatGPT 帳號的模型，`DELETE` 中斷連線。變更需傳入目前 `version`、JSON body 與 `X-EduForge-CSRF` 標頭。

`POST /api/v1/model-connection/test` 以少量結構化輸出測試模型，計入每日生成次數。`GET /api/v1/model-connection/models` 取得 ChatGPT 帳號可用模型。

`POST /api/v1/model-connection/chatgpt/login` 啟動 OAuth。伺服器保留 nonce、PKCE verifier 與短效 state，以 HttpOnly SameSite cookie 綁定瀏覽器。回呼驗證 ID token 簽章、issuer、audience、到期時間、nonce 及訂閱使用 scope。未通過驗證時保留既有連線。

OAuth 回呼由 Nginx 關閉存取日誌，並使用 `Referrer-Policy: no-referrer` 避免授權碼出現在後續請求的 Referer。
